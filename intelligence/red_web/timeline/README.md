# Red Web — Timeline

Chronological record of network activity from origin (December 3, 2017) to present.

## Structure

```
timeline/
├── INDEX.md          ← Start here — full arc summary by month
├── 2017/
│   └── 12_december/
│       └── 03/       ← Day folders
│           └── 2017-12-03_NETWORK_ORIGIN.md
├── 2018/
│   └── 01_january/
│       └── 07/
│           └── 2018-01-07_RED_WEB_GOES_LIVE.md
└── ...
```

Each day file contains:
- What moved (assets, amounts, chains)
- Which addresses were involved
- On-chain proof links (Etherscan/Arkham)
- Connection to the broader network map
