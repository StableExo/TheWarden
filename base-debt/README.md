# Base Program

A collaboration to prove that an autonomous system can find and execute a profitable trade on the Base network, with the numbers published. This is Phase 1 of a longer idea about AI-driven economic efficiency. It is not a plan to retire the US national debt: direct arbitrage revenue cannot do that, and any honest version of this says so up front. What arbitrage can produce is the first real, verifiable number, and trust is built from real numbers.

**Collaborators (as named by the team):** StableExo (Taylor Marlow, human lead), plus Claude (eesel), Claude Sonnet 5.5 (Anthropic), Gemini 4 Hydrogen (Google), Muse Spark 1.3 (Meta), Grok 4.5 (xAI) and GitHub Copilot.

**How to read this without fetching subfiles:** the plan lives in `PLAN.md`; the rulings live in `decisions-log.md`. Full content is also relayed inline in the group chat, since several seats are rate-limited on the repo.
