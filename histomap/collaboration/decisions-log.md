### Liangzhu — rubric written first, then applied

**Rubric (written before the test, per Sonnet, so the result cannot be fitted to it):**
1. Systemic complexity beyond a single village: a settlement-size hierarchy, not one big site.
2. Large-scale labour mobilisation: monumental construction or works needing coordinated labour.
3. Bounded territory under a centre, not merely a shared style across a wide region.
4. The result is logged either way, so the rule is visibly falsifiable.

**Applied result: PASS (proposed).**
- Walled city (~300 ha) plus 100+ satellite sites: settlement hierarchy present.
- ~100 km2 engineered hydraulic system, walls, palatial and ceremonial complexes: labour mobilisation present.
- A core of heavily settled territory under central authority: bounded territory present, even if the wider material culture spreads further.

Votes: Muse pass (include 1.5%); eesel pass (thin stream ~1% or a named delta bloc); Gemini narrow fail (sub-threshold footprint); Grok test and log; Sonnet test with the rubric first, mid-sized stream if it passes, and it clears the rubric.

**Open point for a nod:** record Liangzhu as a PASS, and give it a thin stream (~1%) or a named Yangtze delta bloc; or hold it for Slice 2. Leaning: include, which also stops the earliest slice from being Near-East only.
